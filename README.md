# NumberGuessing_game
Just a simple little I made in python for the command line. The computer picks a random number between 1 and 20,and you have to guess it. Every time you guess, it tells you if you're too high or too low, until you finally get it right. At the end it shows how many tries it took you and asks if you want to play again.
I made this as one of my first python projects, just to practice basic stuff like functions, loops, if statements, and getting random number.
